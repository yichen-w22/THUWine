# 清华葡萄酒协会推送工作区

处理本目录的推送时，先读 `SKILL.md`，按需读 `WORKFLOW.md`。

- 默认使用 `theme.json` 的字体、字号、颜色、间距和组件，不为每篇重新设计。
- 默认不加入协会logo，也不自动给新推送添加logo；仅在用户针对某篇明确要求时使用。共用assets中的原稿保留供按需使用。
- 用户决定内容来源、总体风格、内容顺序；缺失信息不得自行补成确定事实。
- 每篇文字的唯一来源是 `projects/<日期或活动名>/正文.md`；`post.json` 保存组件、顺序、图片与文字引用，不能直接把 `$text` 引用替换成重复文案。图片先复制到该项目的 `assets/`；共用标志放根目录 `assets/`。禁止依赖临时文件。
- 先生成 `preview/index.html` 供用户在内置浏览器批注。处理批注后重新生成同一路径并简短报告实际改动。
- 用户明确同意导出后，才记录当前版本的 approval 并导出分段图。不能把“继续修改”“查看进度”或沉默视为同意导出。
- 默认交付等宽分段图，宽 1080px，按内容边界连续切分。不要额外生成整张长图、PDF、说明附件，除非用户要求。
- 改文字用 `正文.md`；改组件顺序、图片或裁切用 `post.json`；改统一规范用 `theme.json`。组件增删后执行 `markdown-refresh`，先保留已编辑的正文，再更新编辑区域。只有新增组件或修复行为才修改 `scripts/`。
- 用户自行用Typora编辑正文时，启动 `serve <项目名>` 提供本机自动预览；保存后自动重建、刷新。出错保留上次有效页面，错误原因显示在网页角落。不要静默丢弃未绑定区域的文字。
- 当前模板没有自动发布公众号、秀米或发送消息的授权。
